# 2.1. Назначение, границы и основания

Раздел содержит требования к киоску заказа, табло готовности и мобильному приложению системы «Приложение для заказа + табло». Критерии приемки и задачи историй приведены в [разделе 6](../06-zadachi/index.md), тест-кейсы — в разделе 7.

Основной поток: гость выбирает блюда, проверяет и оплачивает заказ, кухня получает оплаченный заказ, табло показывает готовность, гость получает заказ. Без QR заказ анонимный. Идентификация по QR внешней системы лояльности необязательна.

Границы проекта приведены в [разделе 1.6](../01-biznes-trebovaniya/1.6-granicy.md). Для смежных систем указаны только входные данные и ожидаемый результат, их устройство в документе не описано. Интеграции с ними приведены в разделе 4.

Основания: бизнес-процессы [БП-01](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-01)–[БП-06](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-06), [БП-09](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-09) и [БП-10](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-10).
