# 7.4. Чек-лист приемки

Чек-лист используется для итоговой проверки MVP перед пилотом, результат отмечается значениями «OK», «Fail» или «N/A».

Таблица 7.19 — Чек-лист приемки MVP
{: #tablitsa-7-19 .caption }

| № | Проверка | Ожидаемый результат | Результат |
| --- | --- | --- | --- |
| 1 | Меню: категории, вложенные категории, блюдо без признака «В продаже» | Блюда в продаже показаны в своих категориях, снятые с продажи скрыты |  |
| 2 | Корзина и состав блюда: добавление, количество, исключение и добавление ингредиентов | Сумма пересчитывается, наценки учтены, запрещенные изменения недоступны |  |
| 3 | Акции: «2 по цене 1», несколько акций, истекшая акция | Цена по [таблице 7.1](7.1-podhod-k-proverke.md#tablitsa-7-1), сообщение при изменении суммы |  |
| 4 | Оплата картой: успех, ошибка, нет ответа терминала | «Оплачен» и номер; «Ошибка оплаты» и повтор; ожидание без успеха |  |
| 5 | Оплата наличными: П1–П4 [таблицы 7.2](7.1-podhod-k-proverke.md#tablitsa-7-2) | Результат по [таблице 7.2](7.1-podhod-k-proverke.md#tablitsa-7-2) |  |
| 6 | Номер заказа на фискальном чеке, сбой печати | Номер на экране, на чеке и на табло совпадает; при сбое печати номер остается на экране |  |
| 7 | Фискальный чек: оплата картой и наличными, сбой фискального регистратора, чек возврата | Чек печатает фискальный регистратор, данные в ОФД; при сбое — уведомление сотруднику, заказ на кухне |  |
| 8 | Кухня и табло: прием, готовность, выдача, недоступность кухни | Статусы на табло не позднее 3с; первая попытка, три повтора и уведомление при сбое |  |
| 9 | Табло: потеря и восстановление связи | Отметка о неактуальности; актуальные статусы не позднее 10с |  |
| 10 | Внешняя система лояльности не отвечает | Не позднее 3с заказ продолжается анонимно |  |
| 11 | Возврат картой и наличными, отказ, повтор | Статусы возврата и заказа по [ПР-15](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-15) «Возврат оплаты», запись в журнале |  |
| 12 | Торговый день: открытие, закрытие с незавершенными заказами | Новые заказы не принимаются, неоплаченные отменены, оплаченные ведутся до выдачи |  |
| 13 | Бездействие гостя: предупреждение, завершение, исключения | Корзина очищается; при оплате и внесенных наличных сеанс не завершается |  |
| 14 | Доступ: операции сотрудника с токеном киоска | Ответ 403 |  |
