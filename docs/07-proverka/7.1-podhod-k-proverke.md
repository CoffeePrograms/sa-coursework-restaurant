# 7.1. Подход к проверке

Полные тест-кейсы составлены для историй MVP, для историй Релиза 1 приведены названия тест-кейсов. Каждый критерий приемки проверяется хотя бы одним тест-кейсом. Идентификатор тест-кейса TC-NN-k: NN — номер истории, k — порядковый номер.

Проверка выполняется на тестовом стенде с эмуляторами терминала оплаты, фискального регистратора, ОФД, кухни и кассового оборудования киоска и с тестовыми стендами внешних систем. Техники: классы эквивалентности, граничные значения, таблица решений. Тестовые данные приведены в [таблице 7.1](#tablitsa-7-1), таблица решений для оплаты наличными — в [таблице 7.2](#tablitsa-7-2).
