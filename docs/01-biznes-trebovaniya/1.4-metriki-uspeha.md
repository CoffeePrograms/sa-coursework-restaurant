# 1.4. Метрики успеха

Целевые значения метрик для пилота в одном ресторане приведены в [таблице 1.1](#tablitsa-1-1) и являются предварительными. Метрики относятся к MVP. Сроки реализации MVP приведены в [таблице 2.5](../02-trebovaniya/2.6-karta-polzovatelskih-istoriy.md#tablitsa-2-5).

Таблица 1.1 — Цели и метрики успеха MVP
{: #tablitsa-1-1 .caption }

| Цель | Метрика | Ориентир MVP |
| --- | --- | --- |
| Скорость | среднее время «старт заказа — успешная оплата» | сокращение на 20–30% относительно кассы |
| Ошибки | доля заказов с ручной правкой на кухне из-за неверного состава | ≤ 2% |
| Табло | доля оплаченных заказов со статусом «Готов» на табло до выдачи | ≥ 98% |
| Самообслуживание | доля оплаченных заказов через киоск | ≥ 60% за 3 месяца после запуска MVP; заказ через мобильное приложение — ориентир Релиза 1 |
| Штат | сокращение ставок кассовой линии | −1 ставка кассира на ресторан; −2 ставки для большого ресторана; при сохранении выручки |
| Стабильность операций дня | стабильность открытия и закрытия торгового дня | доля смен с инцидентом открытия или закрытия торгового дня &lt; 2% |
