# 1.3. Требования бизнеса

- Гость оформляет заказ без участия кассира и получает понятную информацию о готовности заказа к выдаче.
- Ресторан повышает пропускную способность при том же посадочном зале и снижает долю ручного ввода заказа.
- Бизнес сокращает загрузку кассовой линии и связанные затраты на персонал.
- Операции обеспечивают непрерывный поток «заказ — оплата — кухня — выдача» без потери статусов заказа.
- Эффект внедрения оценивается по измеримым показателям.
