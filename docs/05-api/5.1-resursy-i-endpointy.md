# 5.1. Ресурсы и эндпоинты

Клиенты обращаются к API через API Gateway, базовый путь — /api/v1. Данные передаются в JSON. Суммы передаются строкой в рублях с двумя знаками после точки, например «450.00», дата и время — в формате ISO 8601 с часовым поясом. Значения статусов и перечислений совпадают с [таблицей 3.3](../03-informacionnaya-model/3.5-perechisleniya-i-statusnye-modeli.md#tablitsa-3-3). Киоск и табло аутентифицируются токеном устройства, сотрудник — токеном Сервиса авторизации, гость в мобильном приложении — токеном внешней системы лояльности.

Ресурсы API приведены в [таблице 5.1](#tablitsa-5-1) по группам. Группы совпадают с тегами спецификации OpenAPI в файле order\_api.yaml.
