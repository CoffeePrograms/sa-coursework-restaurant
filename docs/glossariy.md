# Глоссарий

| Термин | Определение |
| --- | --- |
| AC | Acceptance Criteria — критерий приемки пользовательской истории |
| API | Application Programming Interface — программный интерфейс системы |
| C4 | Нотация схем архитектуры по уровням: контекст, контейнеры, компоненты |
| DoD | Definition of Done — условия, при которых история считается выполненной |
| DoR | Definition of Ready — условия, при которых история готова к разработке |
| MVP | Minimum Viable Product — минимально жизнеспособный продукт |
| SSE | Server-Sent Events — поток событий от сервера к клиенту поверх HTTP |
| US | User Story — пользовательская история |
| Акция | Ограниченное по времени ценовое предложение на блюда меню |
| Блюдо | Позиция меню, доступная для выбора гостем |
| БП | Бизнес-процесс |
| Возврат | Возврат оплаты гостю по оплаченному заказу |
| Гость | Посетитель ресторана, оформляющий заказ на киоске или в мобильном приложении |
| Задача | Часть работы по пользовательской истории в одном или двух компонентах системы |
| Заказ | Набор блюд с количеством и ценой, оформленный гостем на киоске или в мобильном приложении |
| Ингредиент | Продукт, который входит в базовый состав блюда или доступен как добавка только для конкретного блюда |
| Инцидент | Сбой, из-за которого торговый день нельзя открыть или закрыть без ручного обхода |
| Киоск | Устройство самообслуживания в ресторане для оформления и оплаты заказа гостем без участия кассира |
| Корзина | Набор блюд, выбранных гостем на киоске или в мобильном приложении при формировании заказа |
| Кухня | Система управления производством, которая получает оплаченный заказ и передает его статусы |
| Мобильное приложение | Приложение гостя для заказа, оплаты и отслеживания статуса заказа вне киоска |
| Модификатор позиции | Зафиксированное в позиции заказа исключение или добавление ингредиента |
| Номер заказа | Короткий номер, который гость получает после успешной оплаты и видит на экране киоска и фискальном чеке, на табло и в мобильном приложении |
| НФТ | Нефункциональные требования — требования к качеству работы системы |
| Облачная касса | Онлайн-касса оператора, которая формирует электронный чек при оплате в мобильном приложении |
| ОГР | Ограничение — условие, которое сужает функции продукта |
| Отзыв | Оценка выданного заказа от 1 до 5 и необязательный текст гостя |
| ОФД | Оператор фискальных данных — принимает фискальные данные чеков и передает их в ФНС |
| Панель персонала | Рабочее место сотрудников: уведомления о сбоях, возвраты, повтор передачи на кухню, отзывы и отчеты |
| Платеж | Попытка оплаты заказа способом «Карта» или «Наличные» и ее результат |
| Платежный сервис | Внешний сервис онлайн-оплаты картой в мобильном приложении |
| Платежный шлюз банка-эквайрера | Система банка-эквайрера, которая проводит оплату и возврат картой на терминале оплаты |
| ПР | Правило — проверяемое утверждение бизнес-логики |
| Состав блюда | Перечень ингредиентов конкретного блюда с признаками допустимого исключения и добавления и наценкой за добавление |
| Сотрудник | Работник ресторана с правами на открытие и закрытие торгового дня, возврат оплаты, подтверждение возврата наличными и повтор передачи на кухню |
| Способ получения | Выбранный гостем вариант получения заказа: «В зале» или «С собой» |
| Статус возврата | Состояние возврата: «В обработке», «Подтвержден», «Отклонен», «Ошибка» |
| Статус заказа | Состояние заказа: «Создан», «Ошибка оплаты», «Оплачен», «Готовится», «Готов», «Выдан», «Возврат», «Отменен» |
| Статус платежа | Состояние платежа: «В обработке», «Успешно», «Ошибка» |
| Табло | Экран в ресторане, отображающий для гостей номера и статусы готовности заказов |
| Терминал оплаты (пинпад) | Банковский терминал в корпусе киоска: получает сумму от киоска, проводит оплату или возврат картой через платежный шлюз банка-эквайрера и возвращает результат. Слип терминала — не фискальный чек |
| Тест-кейс | Проверка требования с предусловиями, шагами и ожидаемым результатом |
| Торговый день | Период приема заказов в ресторане |
| Управляющий | Сотрудник с правами на просмотр оценок, отзывов и отчетов |
| Фискальный регистратор | Касса с фискальным накопителем в корпусе киоска: печатает фискальный чек и чек возврата, передает фискальные данные в ОФД |
| Фискальный чек | Кассовый чек по закону 54-ФЗ на бумаге или в электронной форме, который гость получает при оплате и возврате. На чеке киоска печатается номер заказа |
| Цена по акции | Заранее рассчитанная цена порции блюда по акции |
