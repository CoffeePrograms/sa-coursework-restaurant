# 6.5. Истории Релиза 2

Для историй Релиза 2 приведены критерии приемки. Задачи определяются при планировании Релиза 2.

## US-19. Оценка заказа {#us-19}

Критерии приемки приведены в [таблице 6.37](#tablitsa-6-37).

Таблица 6.37 — Критерии приемки [US-19](#us-19)
{: #tablitsa-6-37 .caption }

| Критерий | Сценарий |
| --- | --- |
| <span id="us-19-ac-1"></span>AC-1. Оценка заказа из приложения | Допустим заказ из приложения в статусе «Выдан»<br>Когда гость ставит оценку от 1 до 5 и пишет отзыв<br>Тогда оценка и отзыв сохраняются по заказу<br>Основание: [ПР-21](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-21) «Оценка заказа» |
| <span id="us-19-ac-2"></span>AC-2. Заказ с киоска | Допустим заказ оформлен на киоске с идентификацией по QR и получил статус «Выдан»<br>Когда гость открывает этот заказ в приложении и ставит оценку<br>Тогда оценка сохраняется по заказу<br>Основание: [ПР-21](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-21) «Оценка заказа», [ПР-07](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-07) «Идентификация по QR и анонимный заказ» |
| <span id="us-19-ac-3"></span>AC-3. Анонимный заказ (негатив) | Допустим заказ оформлен на киоске без идентификации по QR<br>Когда гость пытается оценить заказ в приложении<br>Тогда оценка недоступна<br>Основание: [ПР-21](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-21) «Оценка заказа», [ПР-07](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-07) «Идентификация по QR и анонимный заказ» |
| <span id="us-19-ac-4"></span>AC-4. Заказ не выдан (негатив) | Допустим заказ в статусе «Готовится»<br>Когда гость пытается оценить заказ<br>Тогда оценка недоступна<br>Основание: [ПР-21](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-21) «Оценка заказа» |
| <span id="us-19-ac-5"></span>AC-5. Повторная оценка (негатив) | Допустим заказ уже оценен<br>Когда гость пытается оценить его еще раз<br>Тогда новая оценка не принимается<br>Основание: [ПР-21](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-21) «Оценка заказа» |

## US-20. Просмотр отзывов {#us-20}

Критерии приемки приведены в [таблице 6.38](#tablitsa-6-38).

Таблица 6.38 — Критерии приемки [US-20](#us-20)
{: #tablitsa-6-38 .caption }

| Критерий | Сценарий |
| --- | --- |
| <span id="us-20-ac-1"></span>AC-1. Отзывы за период | Допустим за период есть оценки и отзывы<br>Когда управляющий открывает отзывы за этот период<br>Тогда панель персонала показывает оценки, отзывы, номера и даты заказов<br>И среднюю оценку за период<br>Основание: [ПР-21](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-21) «Оценка заказа» |
| <span id="us-20-ac-2"></span>AC-2. Нет прав управляющего (негатив) | Допустим открыт сеанс гостя или сотрудника без прав управляющего<br>Когда выполняется попытка открыть отзывы<br>Тогда операция отклоняется<br>Основание: [НФТ-07](../02-trebovaniya/2.4-nefunkcionalnye-trebovaniya.md#nft-07) «Разграничение доступа» |

## US-21. Отчеты {#us-21}

Критерии приемки приведены в [таблице 6.39](#tablitsa-6-39).

Таблица 6.39 — Критерии приемки [US-21](#us-21)
{: #tablitsa-6-39 .caption }

| Критерий | Сценарий |
| --- | --- |
| <span id="us-21-ac-1"></span>AC-1. Продажи и средний чек | Допустим за период есть оплаченные заказы<br>Когда управляющий формирует отчет за этот период<br>Тогда отчет показывает сумму продаж, количество заказов и средний чек<br>Основание: [ПР-22](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-22) «Отчеты» |
| <span id="us-21-ac-2"></span>AC-2. Время приготовления | Допустим за период есть выданные заказы<br>Когда управляющий формирует отчет за этот период<br>Тогда отчет показывает среднее время от статуса «Готовится» до статуса «Готов»<br>Основание: [ПР-22](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-22) «Отчеты» |
| <span id="us-21-ac-3"></span>AC-3. Возвраты и отмены (негатив) | Допустим заказ за период получил статус «Возврат» или «Отменен»<br>Когда управляющий формирует отчет<br>Тогда заказ не входит в сумму продаж, количество заказов и средний чек<br>Основание: [ПР-22](../02-trebovaniya/2.3-ogranicheniya-i-pravila.md#pr-22) «Отчеты» |
