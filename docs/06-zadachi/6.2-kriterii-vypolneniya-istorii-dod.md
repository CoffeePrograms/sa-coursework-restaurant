# 6.2. Критерии выполнения истории (DoD)

История считается выполненной, если:

<span id="dod-1"></span>DoD-1. Все задачи истории выполнены, код прошел ревью.

<span id="dod-2"></span>DoD-2. Реализованы ресурсы API раздела 5, спецификация order\_api.yaml соответствует реализации.

<span id="dod-3"></span>DoD-3. Написаны автотесты: модульные тесты правил расчета и статусов, интеграционные тесты API и интеграций, тесты интеграций выполнены на тестовых стендах внешних систем.

<span id="dod-4"></span>DoD-4. Тест-кейсы раздела 7 по истории пройдены, критические и значимые дефекты исправлены.

<span id="dod-5"></span>DoD-5. Для критериев с НФТ выполнены замеры, результат не хуже требования.

<span id="dod-6"></span>DoD-6. События и ошибки пишутся в логи, метрики выведены в мониторинг ([раздел 4.1](../04-arhitektura/4.1-obosnovanie-vybora-arhitekturnogo-stilya.md)).

<span id="dod-7"></span>DoD-7. Экраны соответствуют макетам [раздела 5.4](../05-api/5.4-opisanie-ui-i-vzaimodeystvie-s-api.md).

<span id="dod-8"></span>DoD-8. История принята владельцем продукта на демонстрации.
