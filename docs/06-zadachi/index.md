# 6. Декомпозированные до задач требования

Раздел содержит критерии готовности историй к разработке и выполнения, критерии приемки всех историй и задачи для историй MVP и Релиза 1. Задача — работа в одном или двух компонентах раздела 4. Идентификатор задачи T-NN-k: NN — номер истории, k — порядковый номер. В колонке «Покрывает» указаны критерии приемки, которые реализует задача.
